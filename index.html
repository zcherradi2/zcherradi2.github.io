Selected work

Computah — a screen-aware desktop agent

C# 13, .NET 10, WPF, SQLite, xUnit · solo, 2026

One hotkey captures the screen under your cursor and sends it to an LLM agent. The answer does not just talk: it points at the control you need, frames the region that is wrong, opens a file at the exact line, and — with permission — moves the mouse and types. Local speech-to-text, phone control over Telegram, and every shell command risk-scored and logged.

48 source files · ~13,100 lines · 141 automated tests

DocumentAI — French construction invoices, read automatically

Python, OCR, LLM, scikit-learn · FoliaTech, 2024–2026

An OCR plus LLM pipeline that extracts header fields and line items from invoices that were never meant to be machine-readable. The cost problem mattered more than the model: a classifier trained on 203 annotated documents decides where an LLM is actually needed, so most documents never reach it.

0.885 field-weighted accuracy on held-out documents · ~65% fewer LLM calls per document

Real-estate platform — API and dashboard

REST API with JWT authentication, Swagger, CORS and 13 EF Core migrations across six controllers (auth, properties, proposals, uploads, cities, categories), in repository and service layers, with a typed Angular client on top.

Trading policy learned from scratch

Python, NumPy, PyTorch

A buy/sell/hold policy written as a three-layer network in plain NumPy, then in PyTorch, trained for 250 generations of evolutionary search on XAUUSD minute data, with a paper-trading harness and per-generation checkpoints.
