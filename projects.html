1. Computah - a desktop agent that acts on what it sees

One hotkey, and the screen becomes the conversation

C# 13, .NET 10, WPF, SQLite, xUnit - solo project, 2026

A Windows assistant: a hotkey captures the screen under the pointer, the window's UI elements and the selected text, sends them to a coding agent, and streams the answer into a bubble next to the cursor. The answer can act: point at a control, frame the region that is wrong, open a file at the exact line, show its own edits as a diff with undo, and - with permission - drive the mouse and keyboard.

48 source files, ~13,100 lines, 141 automated tests, every shell command risk-scored and logged

2. DocumentAI - invoices that read themselves

OCR + LLM extraction, measured, with the cost engineered out

Python, OCR, scikit-learn, LLM - FoliaTech, 2024-2026

A pipeline that pulls header fields and line items out of French construction invoices. The interesting half was not the model, it was the cost: a classifier trained on 203 annotated documents decides where a language model is actually needed, so most invoices never reach it. Totals are re-derived from the line items, and an invoice that does not add up is flagged instead of accepted.

0.885 field-weighted accuracy on held-out documents, about 65% fewer LLM calls per document
